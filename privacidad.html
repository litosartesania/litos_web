Política de privacidad

Página de presentación informativa: no se admiten encargos ni se realizan ventas.

Alcance del sitio

LITOS es una presentación informativa que no acepta pedidos, encargos, presupuestos ni pagos. No incluye formularios, boletines, analítica propia ni sistemas de perfilado. El titular del proyecto no dispone de un sistema propio de recogida o tratamiento de datos de visitantes.

Información técnica de GitHub Pages

Esta web está alojada en GitHub Pages. Según la documentación del proveedor, GitHub registra la dirección IP de los visitantes por motivos de seguridad, incluso cuando no inician sesión. Consulte la documentación técnica de GitHub Pages y su declaración de privacidad para conocer el tratamiento y los derechos correspondientes.

Cookies y enlaces externos

El código del proyecto no incorpora cookies publicitarias, fuentes remotas ni seguimiento. Los enlaces a sitios externos no se abren ni transmiten formularios automáticamente; cuando el visitante los utiliza, los proveedores de destino pueden aplicar sus propias políticas.

Derechos

Para el tratamiento de registros técnicos efectuado por GitHub, consulte los canales de privacidad que ofrece el propio proveedor. También puede informarse sobre sus derechos en la Agencia Española de Protección de Datos. Si el proyecto incorpora funcionalidades de tratamiento de datos en el futuro, esta información deberá revisarse antes.
