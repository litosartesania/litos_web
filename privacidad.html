Política de privacidad

Información sobre privacidad y navegación.

Alcance de esta muestra

El formulario visible es una maqueta inactiva. No acepta datos ni envía mensajes. Esta versión no dispone de cuentas, pagos, boletines, analítica propia ni perfilado.

Configurador local

Los textos y la imagen opcional de fotocerámica se procesan en el navegador para mostrar y descargar la composición. La web no los envía a LITOS, no los guarda en un servidor ni los conserva al cerrar la pestaña. Comprueba el archivo descargado antes de compartirlo.

Datos técnicos de GitHub Pages

El sitio está alojado en GitHub Pages. Según su documentación, GitHub registra la dirección IP de los visitantes por seguridad, incluso sin iniciar sesión. Consulta la documentación del alojamiento y la declaración de privacidad de GitHub para conocer sus prácticas y canales de derechos.

Enlaces externos

Este proyecto no incorpora cookies publicitarias, fuentes remotas ni seguimiento propio. Si abres un enlace a una web de terceros, ese sitio puede tratar datos conforme a su propia política. También puedes consultar los derechos de información descritos por la AEPD.
